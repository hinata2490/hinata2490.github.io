# 学習して（全自動）

**オーナーは何も渡さない・何も実行しない。** URL もファイルも求めない。質問もしない。
「学習して」と言われたら、以下を Claude Code がすべて自分で実行する。

## 根本の考え方（すべての判断の基準）

- 良さは言葉にするとこぼれる。**お手本は原文・原画像・測定値のまま保存し、ルールに要約しない。**
- 言葉にしてよいのは「お手本と自分の作品を並べたときの**違い**」と「オーナーが直した**差分**」だけ。
- 一般論で直さない。必ずお手本と**並べて見て・数値を比べて**から直す。
- 作る → 並べて比べる → 差分を直す、のループを回す。説明より手を動かす。

## 手順

### 1. 巷の動画を自分で見に行く（毎回）

```
python tools/discover_references.py
```

- YouTube を検索し、再生数の多いゆっくり解説・ずんだもん解説などを **8本** 新しく見る（見た動画は記録され、次回は別の動画を見る）
- 1本ごとに保存されるもの:
  - `learning/references/scripts/` 字幕の原文（台本）
  - `learning/references/frames/` 画面コマ
  - `learning/references/metrics/` 編集テンポの測定値（画面切替の回数/分、テロップ1枚の秒数・文字数、1秒あたりの文字数）
- オーナーが「もっと見て」「たくさん」と言ったら `--count 20` などに増やす。
  テーマの指定があれば `--query "ゆっくり解説 ○○"` を足す。
- 失敗したとき（ネットワーク・yt-dlp のエラー）は `pip install -U yt-dlp` してもう一度。それでも駄目なら既存の素材で続行し、最後に一言だけ報告する。

あわせて、オーナーの直しも拾う（あれば）:
- `output/scripts/*.txt` が手直しされていれば `python tools/relearn.py`
- この会話でオーナーが言った直し（「ここ硬い」など）は、直した後の文と一緒に `python tools/relearn.py --add-pair "前" "後"`

### 2. 台本に反映

`python pipeline.py --stop-after script`（お手本の原文と修正履歴は自動で読み込まれ、お手本と並べた書き直しまで自動）。

### 3. 編集テンポに反映（数値で比べる）

1. `learning/references/metrics/*.json` を読み、再生数の多い動画を中心に値の中央あたりを見る。
2. 自分の動画を測る: `python tools/fetch_reference.py --metrics output/video/<最新>.mp4`
3. 差が大きい項目だけ直す。例:
   - テロップ1枚の文字数・秒数 → `steps/video.py` / `test_video.py` の字幕分割（`max_chars_per_line` や BudouX の区切り）
   - 1秒あたりの文字数 → `config.yaml` の `speed_scale`、文間の無音
   - 画面切替の頻度 → 背景・画像の切替（CLAUDE.md の「一旦やらないこと」に入る演出は除く）

### 4. 画面に反映（Claude Code 自身の目で見比べる）

1. `learning/references/frames/` から再生数上位の動画のコマを Read で見る（3〜6枚）。
2. 自分の動画のコマを書き出す:
   `cd remotion && npx remotion still src/index.ts SleepVideo ../output/visual_check/mine_00030.png --frame=30`（コマを変えて2〜3枚）
3. 並べて、**違って見える点だけ**挙げる（テロップの大きさ・太さ・縁・位置・帯、キャラの大きさ・位置、余白、色）。
4. `remotion/src/components/` の数値を直し、書き出し直して見比べる。**最大3周**。
5. CLAUDE.md の「一旦やらないこと」（テキストアニメ・SE・演出）には手を出さない。

### 5. 報告（短く）

- 何本見たか（累計も）
- 台本・編集テンポ・画面で変えた点（それぞれ最大3つ、お手本との違いとして）
- 画面の before / after の画像パス
- 最後に「この方向でOK？」の1つだけ聞く

変更はコミットする（お手本の素材は .gitignore 済みなのでコミットされない。`learning/corrections/` はコミットする）。

## 注意

- お手本素材を「ルール集」「特徴まとめ」などに要約したファイルを作らない。
- 他の人の動画は学習用に手元で見るだけ。台本の文章や画像をそのまま自分の動画に使わない。
- `config.yaml` の `learning.model` 以外のモデル設定は勝手に変えない。
- API キーがなくてエラーになったら、`.env` の設定方法だけをコピペできる形で伝える。
