# 学習して（全自動）

オーナーは手順を覚えない・コマンドも打たない前提。**この手順はすべて Claude Code が自分で実行する。**
オーナーに「〜を入れてください」「〜を実行してください」と頼まない（素材が本当にゼロのときの1質問だけ例外）。

## 根本の考え方（すべての判断の基準）

- 良さは言葉にするとこぼれる。**お手本は原文・原画像のまま保存し、ルールに要約しない。**
- 言葉にしてよいのは「お手本と自分の作品を並べたときの**違い**」と「オーナーが直した**差分**」だけ。
- 一般論の「良いデザインとは」で直さない。必ずお手本と**並べて見て**から直す。
- 作って → 並べて比べる → 差分を直す、をループで回す。説明より手を動かす。

## 手順

### 1. 素材を自分で集める（オーナーの今回のメッセージと会話から）

| オーナーが渡したもの | Claude がやること |
|---|---|
| YouTube の URL | `python tools/fetch_reference.py <URL>`（字幕原文と画面コマを自動保存） |
| 動画・画像・字幕ファイルのパス | `python tools/fetch_reference.py <パス>` |
| 台本の文章を貼り付け | `learning/references/scripts/<名前>.txt` に**そのまま**保存 |
| 「ここが硬い」「こう言って」など会話での指摘 | 直す前の文と直した後の文を `python tools/relearn.py --add-pair "前" "後"` で保存 |
| `output/scripts/*.txt` を手で直してある | `python tools/relearn.py`（差分を自動で拾う。直していなければ何も起きない） |
| 何も渡されていない | 既存の `learning/` の中身と、手直し済みの台本だけで続行する |

`learning/references/` が空で、かつ今回何も渡されていないときだけ、1回だけこう聞く:
「お手本にしたい動画のURLを1〜3本貼ってください（台本と画面を自動で取り込みます）」

### 2. 台本に反映

`python pipeline.py --stop-after script` で台本を作る（お手本と修正履歴は自動で読み込まれ、
お手本と並べた書き直しまで自動で行われる）。新しい台本の `revision_differences` を確認する。

### 3. 画面に反映（Claude Code 自身の目で見比べる）

1. `learning/references/frames/` のお手本画像を Read で見る。
2. Remotion で自分の動画のコマを書き出す:
   `cd remotion && npx remotion still src/index.ts SleepVideo ../output/visual_check/mine_00030.png --frame=30`（コマ番号を変えて2〜3枚）
3. 並べて見て、**違って見える点だけ**を挙げる（テロップの大きさ・太さ・縁・位置・帯、キャラの大きさ・位置、余白、色）。
4. `remotion/src/components/` の数値を直し、もう一度書き出して見比べる。**最大3周**。
5. CLAUDE.md の「一旦やらないこと」（テキストアニメ・SE・演出）には手を出さない。

### 4. 報告（短く）

- 何を取り込んだか（1行）
- 台本で変わった点（違いを最大3つ）
- 画面の before / after の画像パス
- オーナーへの質問は「この方向でOK？」の1つだけ

変更はコミットしておく（お手本の素材自体は .gitignore 済みなのでコミットされない）。

## 注意

- お手本素材を「ルール集」「特徴まとめ」などに要約したファイルを作らない。
- `config.yaml` の `learning.model` 以外のモデル設定は勝手に変えない。
- API キーがなくてエラーになったら、`.env` の設定方法だけをコピペできる形で伝える。
