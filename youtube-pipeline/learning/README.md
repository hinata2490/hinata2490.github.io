# 学習（再学習）のしかた

このパイプラインのAIは「ルールの説明」ではなく、**お手本の実物**と**あなたが直した差分**から学びます。
（言葉にしたルールだけを渡すと、良さの大事な部分がこぼれてしまうため）

```
お手本を入れる → 台本を作る → あなたが直す → 再学習 → 次の台本に反映
                                   ↑___________________________|
```

## 1. お手本を入れる（最初に1回、あとは気が向いたら追加）

| 置き場所 | 入れるもの |
|---|---|
| `references/scripts/` | 「この語り口が理想」と思う台本の**原文**を `.txt` で（要約しない）。2〜5本 |
| `references/frames/` | 「この画面が理想」と思う動画のスクショ（png/jpg）。3〜6枚 |

※ 他の人の動画の台本・スクショは GitHub に上がらない設定にしてあります（手元だけで使われます）。

## 2. 台本を作る

```
python pipeline.py --stop-after script
```

生成時にお手本と過去の修正が自動で読み込まれ、
「下書き → お手本と並べて違いを挙げる → 書き直し」まで自動で行われます。

## 3. 台本を直す

`output/scripts/` にできた `.txt` をメモ帳で開いて、**普段の案件と同じ感覚で直して保存**してください。
`## フック (30秒)` のような見出し行は消さないでください。

## 4. 再学習する

```
python tools/relearn.py
```

- 直した箇所（before → after）が `corrections/` に保存され、次回から毎回AIに見せられます
- 直した内容は台本 JSON にも反映されるので、そのまま `python pipeline.py --from-step audio` で続行できます
- 特に出来が良くなった台本は、お手本にも登録できます: `python tools/relearn.py --promote`

## 5. 画面も見比べる（任意）

```
python tools/visual_check.py
```

自分の動画のコマを書き出して `references/frames/` のお手本と並べ、
「違い」と「Remotion でどの数値を変えればいいか」を `output/visual_check/report.md` に出します。
