プライバシーポリシー

最終更新：2026年9月26日

対象

このポリシーは、運営者が個人で使う「YouTube 投稿ツール」に適用されます。このツールは運営者本人の Google アカウントだけで使用します。

取得する情報

Google の OAuth による許可の範囲で、運営者自身の YouTube チャンネルの情報、動画の情報、YouTube アナリティクスの数値を取得します。

使い方

取得した情報は、運営者自身の動画の投稿と、再生状況の分析にだけ使います。

保存と共有

許可の情報（トークン）と取得したデータは、運営者のパソコンの中にだけ保存します。第三者への提供、販売、広告への利用は行いません。

許可の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも許可を取り消せます。

Google API サービスのユーザーデータに関するポリシー

このツールによる Google API から取得した情報の使用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
